## Facts claimed about Jev
- Jev = TypeSafe's "System One" model; answers typed questions about text with calibrated probabilities; does not generate text. Official sites `typesafe.ai`, `docs.typesafe.ai`; GitHub org `typesafe-ai`; console/playground `console.typesafe.ai/playground`; evals app `evals.typesafe.ai`.
- Three primitives: **Choice** (pick one of ≤255 options; returns `choice`, `probabilities`, `confidence`), **Score** (2–10 ordered levels; `score` = probability-weighted level index e.g. 1.2, `legend`, `probabilities`, `confidence`), **Noul** (P(yes) 0–1; no `confidence` field). (AI SDK / Vercel eve call the third primitive "Boolean".)
- Endpoint `POST https://api.typesafe.ai/v1/systemone`; `GET /v1/models`; `Authorization: Bearer $TYPESAFE_API_KEY`. Request: `model`, `state`, `questions` {id: {type, instructions, criteria}}. Response: `model`, `answers`, `usage` {input_tokens, output_tokens}.
- Cheatsheet "last checked 2026-09-21 against `jev-1.13.0`, `typesafe-sdk` 0.7.0 (Python), `@typesafe-ai/sdk` 0.6.0 (JS)". Aliases `jev-latest` and `jev-preview` both → jev-1.13.0.
- Price **$0.042 per million input tokens; output tokens free** (also Cloudflare catalog entry repeats this).
- Rate limits 250,000 tokens/s and 1,200 requests/min (dynamic; 429). Context **64k tokens per request; 32k for state + longest question**. Latency "about 100 ms for most queries, per the docs". Text-only input. No fine-tuning. English works best; test other languages incl. CJK.
- SDKs: Python `pip install typesafe-sdk` (import `typesafe_sdk`, `TypeSafeClient`, `AsyncTypeSafeClient`, `client.system_one(...)`, Python 3.10+); JS `npm install @typesafe-ai/sdk` (`client.systemOne`, Node 20+). Env vars `TYPESAFE_API_KEY`, `TYPESAFE_BASE_URL`, `TYPESAFE_DEFAULT_MODEL`, `TYPESAFE_LOG_LEVEL`. Official GitHub repos typesafe-sdk-python (⭐190), typesafe-sdk-js (⭐216), typesafe-ai/skills (agent skill, installable as Claude Code plugin or skills.sh).
- Training: "reinforcement learning for calibrated decisions (RLCD)". Launch blog "Introducing System One models and Jev" dated 2026-09-15; HN launch thread ~2,000 points / ~500 comments. Founder Diogo Almeida's launch thread claims "20-200x faster and 40-400x cheaper" than frontier chat models.
- Gateways: OpenRouter (`openrouter.ai/typesafe/jev`, "Decisions API", described as alpha), Vercel AI Gateway, OpenCode Zen (serves Jev 1.13, plus limited-time free `jev-1.13-free`), Convex AI Gateway (`typesafe/jev-1.13`), Cloudflare catalog (`typesafe/jev`), Bifrost, new-api (jev-1.13.0, jev-latest, jev-preview), GPT-Load.
- Community measurements: p50 ~150ms / p95 ~350ms over ~5,000 requests for ~$2 (MichaelLee04); 1,700 emails sorted for 18 cents; OpenRouter Ori Eval: Jev >5x faster than next-fastest judge; security pipeline 99.3% accuracy at 0.259s, $0.026/1K; industrial email benchmark 96.4% vs Gemini 97.5%/98.5%, none of 737 answers at ≥99% confidence wrong; JevBench (benchmarkheaven) Jev 75.3 vs SemIf 74.6; Terra-tier on MMLU/GPQA except math; "$200 test": 100x cheaper roughly holds, 100x faster does not; calibration study (~37,000 items) found Jev often overconfident; Kepler test 54.2% vs 64.4% rule baseline; reranking alone +0.012 NDCG@10 over bge-m3; Hermes Agent scorecard recommends against Jev compaction (0.5 default kept none of 851 calls).
- Contradiction/nuance: official "~100 ms" vs community p50 150ms / 250–500 ms measured; "calibrated" vs independent finding of overconfidence.

## Key insights / patterns
- Mental model: one **state** + many independent typed **questions**, evaluated in parallel and in isolation (questions can't see each other). Code owns control flow.
- Question design: one judgment per question; one condition per Noul; phrase the positive case (for verification make failure = true); Score levels as concrete situations, not bare numbers; question IDs are never sent to the model; reference nested state with backticked paths.
- Choice always sums to 1 → add `other`/`none` or a gate Noul. Multi-label → one Noul per label. Noul 0.5 ≠ "medium".
- Confidence: three-path routing (act / confirm / human), thresholds scale with risk, uncertainty band (0.30–0.70) for Nouls, "weakest link wins" (min confidence), confidence ≠ correctness — tune on labeled data and pin versioned model IDs since `jev-latest` moves.
- Composition moves: speculative fan-out, confidence-gated routing, composite scoring, select-don't-generate, model-reads-code-computes, rank by Noul, gate-then-decide, taxonomy beam search, back-off to parent category, verify-and-escalate cascade, judgments-as-features, Score levels as actions.
- Jaggedness in 1.13: literal reading of scoping/negation, counting/arithmetic/numeric formats, date comparison, double negatives/multi-hop, irrelevant large state, adversarial text, instructions contradicting criteria, equivalent questions disagreeing (Noul vs yes/no Choice), text generation.
- When not to use: text outputs; exactly computable tasks; extended reasoning; replacing ordinary control flow with agent loops; guardrail Noul as sole security boundary; calling from browser (keep keys server-side).
- Recurring use cases: coding-agent permission/auto-mode reviewers, model routers (reasoning effort), context compaction (contested), PR review, browser agents, trading bots, moderation, reranking, LLM-as-judge replacement.
- Open clones: Laya, SemIf (ex-OpenJev), Kev, NanoJev, Bespoke Nimble (90.1% agreement with Jev), vLLM DiffusionGemma mode — self-reported accuracy generally below Jev.
